# Code of conduct

Be kind and be useful. Disagree with ideas, not people. No harassment, personal attacks or discrimination.
Maintainers may remove comments, issues or contributions that break this and may block repeat offenders.
Report problems privately to the repository owner via the GitHub profile contact.

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
